# Contributing to Conake Browser

Thanks for checking out Conake Browser.

This repository is the public collaboration hub. The main application source is private, so access is granted only when a task actually requires it.

## Before asking for source access

Please open an issue and introduce yourself first.

Include:

- GitHub username
- Languages/frameworks you use
- Relevant projects, if any
- What area interests you
- Rough experience level

## First-task rule

New collaborators start with one small, clearly defined task.

Good first tasks are:

- A reproducible bug fix
- A regression test
- A small UI improvement
- Performance investigation
- Documentation
- Platform testing

The goal is to make sure the workflow works for both sides before increasing access or responsibility.

## Branch workflow

If you receive access to the private source repository:

1. Do not develop directly on `core`.
2. Create a feature branch.
3. Keep the change focused on one task.
4. Run the relevant tests.
5. Open a pull request into `core`.
6. Explain what changed and how you tested it.
7. Wait for review before merging.

Example branch names:

- `fix/android-address-bar`
- `perf/tab-switching`
- `test/extensions-regression`
- `feature/bookmark-search`

## Security

Never request, share, or commit:

- GitHub passwords
- Personal access tokens
- API keys
- Cloudflare credentials
- Signing keys
- Private account credentials

Secrets do not belong in source code, screenshots, issues, pull requests, or chat logs.

## Payment

Conake currently has no development budget. Contributions are voluntary and unpaid unless a separate written agreement explicitly says otherwise.

There are no required hours.

## Credit

Accepted contributors keep their Git commit attribution and may be recognized in project documentation.

## Conduct

Keep technical discussion focused and respectful. Critique code, not people. Avoid destructive changes, hidden behavior, credential collection, or code intended to weaken user security.

Small, reviewable PRs beat giant mystery commits.
